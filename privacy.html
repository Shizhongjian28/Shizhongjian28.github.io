Privacy Policy

Updated October 28, 2026. Emory Mail Delivery Verifier is a personal application used only by its owner.

Google data accessed

The application requests the Gmail read-only OAuth scope. It searches the owner’s Gmail messages for exact, unique forwarding traces and reads the matching message’s subject and Gmail labels. It checks Inbox, All Mail, Spam, and Trash to distinguish delivery from filtering.

Use and storage

The application uses this data only to confirm delivery of mail forwarded from the owner’s Emory Exchange account. A Gmail OAuth refresh token and client configuration are held in the owner’s macOS Keychain. A local SQLite database stores trace IDs, source message identifiers, submission state, verification results, and errors. The application does not upload Gmail content to this site or any other server and does not share or sell Google user data.

Retention and control

The owner can stop or pause the service at any time with its local command-line tool, remove the local database, and revoke OAuth access from Google Account settings. The application retains local checkpoints until the owner deletes them to prevent duplicate forwarding.
