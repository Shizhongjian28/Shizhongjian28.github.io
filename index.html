Emory Mail Delivery Verifier

This is a personal, local Mac application that checks whether email explicitly forwarded from the owner’s Emory mailbox has arrived in the owner’s Gmail account. It runs on the owner’s computer and uses Gmail read-only access solely to search for unique delivery traces and read delivery labels, including Spam and Trash. Forwarding itself is performed by Apple Mail.

The application does not sell, share, or use Gmail data for advertising. It stores a refresh token in the macOS Keychain and delivery checkpoints in a local SQLite database. No Gmail message content is sent to this website.
